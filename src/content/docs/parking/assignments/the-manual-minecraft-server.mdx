You and your team have been hired by a secretive startup, 'Glittering Prizes Inc.', whose sole purpose is to provide a 'morale-boosting' private Minecraft server for its overworked employees. Your first task is a trial by fire: get a server running, and do it all by hand in the cloud. You'll need to manually set up the networking, launch an EC2 instance, install the Java and Minecraft server software, and meticulously configure the world's `server.properties`. Document everything in a 'Sysadmin's Survival Guide' so the next person doesn't have to start from scratch. The employees are waiting to start building... no pressure.

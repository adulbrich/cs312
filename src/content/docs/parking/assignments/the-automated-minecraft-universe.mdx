The 'morale-boosting' server was a wild success! Now 'Glittering Prizes Inc.' wants new servers for different teams: a 'Creative Mode' world for the designers and a 'Hardcore' world for the developers. Setting them up manually again would be madness. It's time to upgrade from a crafter to a redstone engineer. Your team will automate the entire process. Use Terraform to build the infrastructure with code, and an Ansible playbook to install the software and deploy the correct `server.properties` for each world type. Your goal is a Git repository that acts as a magic button: push a new branch, and a new, perfectly configured Minecraft world appears.

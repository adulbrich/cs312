This schedule shows the 10-week plan for lectures, labs, and assignments. Lectures cover the concepts needed for the upcoming lab, ideally one week in advance but at minimum by the first lecture of that lab's week.

- **Lectures:** Two 1-hour-20-minute sessions per week.
- **Labs:** Due on **Fridays** (multiple sections per week).
- **Assignments:** Due on **Sundays at 11:59 PM**, every two weeks starting in Week 2.

<Aside type="caution">
This schedule is subject to change. Always check Canvas for the most up-to-date due dates.
</Aside>

## Week 1: Hardware and Virtualization

| | |
|---|---|
| **Lecture 1** | [Hardware Fundamentals](/lectures/hardware-fundamentals/) |
| **Lecture 2** | [Virtualization and Virtual Machines](/lectures/virtualization-basics/) |
| **Lab 1a** | [The Bare Metal](/labs/the-bare-metal/) |
| **Lab 1b** | [Cloud Environment Setup (AWS Academy)](/labs/cloud-environment-setup/) |

Hardware Fundamentals supports the Bare Metal lab. Virtualization is introduced this week so you understand what a virtual machine is before spinning one up in Lab 1b: an EC2 instance is a VM running on AWS's infrastructure.

| | |
|---|---|

## Week 3: Containers and Cloud Services

| | |
|---|---|
| **Lecture 5** | [Containerization with Docker](/lectures/containerization-with-docker/) |
| **Lecture 6** | [Cloud Computing and VM Deployment](/lectures/cloud-computing-and-vm-deployment/) |
| **Lab 3** | [Containerizing a Web Application (Docker Compose)](/labs/containerizing-a-web-application/) |

Docker builds directly on the VM foundation from Week 1: containers share a kernel instead of virtualizing hardware. Cloud Computing is introduced Thursday to cover S3, ECR, IAM roles, and VPC design one full week before you use ECR and S3 in Lab 4.

|---|---|
